{#- ============================================================================ Nepal Gas — Sales Invoice on ORDINARY A5 PAPER ============================================================================= STANDALONE. This file deliberately does not include or extend nepal_gas_invoice.html: that template drives the LIVE pre-printed dot-matrix formats and must not move while this one is being tested. The coordinate map P below is copied from it, not imported, so the two can be calibrated and evolved independently (same convention as escp_avinash_slip.py vs escp_invoice.py). WHY THIS EXISTS --------------- The raw-ESC/P -> Print Bridge -> Epson LQ-310 path is not stable enough to run across branches that are hundreds of km apart: every failure needed either an on-site visit or a hand-typed PowerShell session. This format sidesteps the whole transport. It prints the form furniture as well as the data, so it needs NO pre-printed stationery, NO tractor feed, NO dot matrix and NO local agent — just an ordinary printer with A5 paper, through the normal PDF path. THE TWO FAILURES THIS IS BUILT TO AVOID --------------------------------------- Both of the problems the team hit before have the SAME root cause: the PDF declared a page size (241.3 x 139.7mm, the 9.5x5.5in continuous form) that the printer driver did not have loaded. The driver fell back to its own media (A4) and improvised. 1. "One page took two sheets." A4 is 297mm long and the form is 139.7mm, so a single A4 page pushed TWO forms through the tractor. Fixed here by using a REAL, STANDARD sheet size: one @page == one physical A5 sheet. Nothing is left for the driver to guess, and there is exactly one sheet per copy with no trailing blank page (see the .last rule below). 2. "The whole print came out rotated 90 degrees." The driver believed A4 portrait was loaded and rotated the landscape form to make it fit. Defended two ways: orient = 'landscape' (default) -> A5 landscape, 210 x 148mm. Correct for any printer whose tray/driver is set to A5. Reads normally. orient = 'portrait' -> A5 PORTRAIT, 148 x 210mm — the least ambiguous page a driver can be handed — with the form rotated 90deg INSIDE it. Nothing anywhere in the chain has to rotate, so the output is deterministic on a printer locked to portrait. Turn the sheet a quarter turn to read it. Use this one if rotation ever comes back. GEOMETRY -------- No coordinate in P was re-measured for A5. The form is cropped to the area that actually carries ink and that crop is scaled by ONE uniform factor, so every measured position keeps its exact relationship to every other one; only the absolute size changes. Text scales with the boxes, so the proportions stay as calibrated. P itself came from a CamScanner scan of a printed Narayani form, metrically rectified by fitting a homography to all 22 sprocket-hole centres (0.39mm mean / 0.99mm max residual), with the form furniture re-calibrated against a sprocket-rectified photo of a blank NGI form (0.42mm mean).
